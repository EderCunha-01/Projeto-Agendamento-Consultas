# Projeto de Agendamento de Consultas Médicas

## 📌 Descrição do Projeto
Este projeto consiste no desenvolvimento de um aplicativo móvel para agendamento de consultas médicas.  
O sistema contempla funcionalidades como:
- Cadastro de usuários
- Gestão de agenda médica
- Agendamento de consultas
- Notificações
- Integração com sistema externo de prontuário eletrônico

O projeto encontra-se em fase intermediária de desenvolvimento, com parte das funcionalidades já implementadas e outras em progresso.

---

## 🎯 Objetivo do Exercício
O objetivo deste exercício é aplicar práticas de **gerenciamento de projetos de software**, com foco em:
- Identificação e análise de riscos
- Definição de estratégias de resposta
- Comunicação estruturada com stakeholders
- Organização de entregáveis em repositório

---

## 📂 Organização do Repositório
O repositório está estruturado em pastas para facilitar a organização dos materiais:

- **/riscos**  
  Contém documentos relacionados à identificação, análise e estratégias de resposta aos riscos do projeto.  
  Exemplos: lista de riscos, matriz de probabilidade x impacto, plano de mitigação.

- **/comunicacao-stakeholders**  
  Contém materiais de comunicação voltados aos stakeholders, como relatórios, mensagens de atualização e planos de alinhamento.  
  Exemplos: comunicados formais, apresentações executivas, resumos de status.
